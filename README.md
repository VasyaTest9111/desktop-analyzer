# OMEGA Desktop Analyzer

Перший публічний компонент архітектури OMEGA. 
Інструмент для створення інтелектуальних знімків робочого простору для ШІ-агентів.

## Призначення
Цей скрипт допомагає ШІ-агентам миттєво зрозуміти контекст вашого робочого середовища, аналізуючи структуру папок та метадані файлів без завантаження зайвого "шуму".

## Особливості
- Валідація структури **Johnny Decimal** та **PARA**.
- Компактний Markdown-звіт.
- Автоматичне ігнорування системних директорій.
